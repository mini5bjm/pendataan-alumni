Aturan Keamanan Cloud Firestore (Rules)

Salin dan tempelkan ke tab "Rules" di Firebase Console

Aturan ini memberikan izin baca untuk portal publik (wali murid & siswa), izin update formulir, serta izin kelola data bagi admin sekolah: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /students/{studentId} {
      allow read: if true;
      allow create: if request.resource.data.namaSiswa is string && request.resource.data.idSiswa is string;
      allow update: if request.resource.data.namaSiswa is string;
      allow delete: if true;
    }
    match /settings/{settingId} {
      allow read: if true;
      allow write: if true;
    }
    match /users/{userId} {
      allow read: if true;
      allow write: if true;
    }
    match /responses_archive/{archiveId} {
      allow read, write: if true;
    }
  }
}
Cara Memasang di Firebase Console:
  1. Buka Firebase Console > Pilih Proyek Anda.
  2. Klik menu Build > Firestore Database > Klik tab Rules.
  3. Hapus aturan lama, tempel kode di atas, lalu klik Publish.
